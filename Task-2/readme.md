
# Inventory Management System

A user-friendly Inventory Management System built using Python's Tkinter and OpenPyXL. It allows users to manage products, including adding, editing, deleting, and keeping track of low-stock alerts.

## Features

- **Add, Edit, and Delete Products**: Easily manage your inventory by adding new products or updating and removing existing ones.
- **Low Stock Alert**: Get warnings when any product falls below the defined stock threshold.
- **Inventory Preview**: View all products in a clean, tabular format.
- **Excel Integration**: Save and load inventory data directly from an Excel file.

## Requirements

- Python 3.x
- Tkinter (usually comes pre-installed with Python)
- OpenPyXL

## Usage

1. **Add Product**: Fill in the product details and click `Add Product`.
2. **Edit Product**: Select the product, update details, and click `Edit Product`.
3. **Delete Product**: Select the product and click `Delete Product`.
4. **Low Stock Alert**: Check for products with quantities below the threshold.
5. **Preview Inventory**: View the current list of products and their details.
